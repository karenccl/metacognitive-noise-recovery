# Metacognitive Noise Recovery with `hmetad`

**Short title:** Static meta-d′ estimation under dynamic confidence generation and distributional misspecification

Reproducible simulation study (R-only, no human-data collection) evaluating whether a static
Gaussian meta-d′ model fitted with `hmetad` recovers the intended ordering of metacognitive
efficiency when confidence is generated by a DDM-type process with post-decisional readout
noise (G1), and how inference/posterior-predictive fit change under non-Gaussian
distributional misspecification (G2), benchmarked against a model-consistent baseline (G0).

Full design and locked decisions: see [docs/design_decisions.md](docs/design_decisions.md).

## Status

Scaffolding stage — repository structure created; simulators, fitting pipeline, and analyses
not yet implemented. See `docs/analysis_log.md` for progress.

## Research questions

- **Primary (G1):** Under a DDM-type confidence generator with readout noise σ_c, does
  posterior `log_M` from `hmetad` decline monotonically as σ_c increases?
- **Secondary (G2):** When the signal distribution is non-Gaussian, how much do inference and
  posterior predictive fit change when fitting the default Gaussian model versus the correctly
  specified alternative distribution?

## Installation

Requires R, [renv](https://rstudio.github.io/renv/), and a working CmdStan installation via
`cmdstanr`. See `docs/computational_environment.md` for verified versions.

```r
renv::restore()
options(brms.backend = "cmdstanr")
stopifnot(!is.null(cmdstanr::cmdstan_version()))
```

## Reproduction

```bash
make all
```
